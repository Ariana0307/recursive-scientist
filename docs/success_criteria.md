# Recursive Scientist 正式成功标准 — G4 r1

适用边界：此规则基于独立审查的 G3 baseline runner `931049af15ddafa12a5163e924a3ea84bbfbbf3f`；本版正式搜索尚未开始，G4 GPU 授权为 0。规则、最终测试协议与搜索排程由本次文档提交和文件 SHA256 冻结。科研 Agent 对标准没有修订权；不得让其编辑规则、评分、额度或获取 shell/文件工具。可信操作者负责按锁定版本执行和审计，不能把研究模型输出当规则变更授权。

这是角色/受信任操作者边界，不声称同 UID 任意 shell 进程在 OS 层无法改文件。主控需要更正时必须显式审阅新版本、记录理由与影响；不能因已见搜索/test成绩修改同一轮成功定义。正式搜索开始后不接受研究 Agent 的标准改写；必要的协议变更终止原轮结论适用性，不能事后美化结果。

## 三类成功分开判定

| 成功类别 | 必要条件 | 当前证据状态 |
| --- | --- | --- |
| 流程成功 | 真实 Omnigent 角色链、真实授权实验与校验结果；结果确实改变下一步的配置/排序/停止决定，并落实为实际下一动作。消息、工具调用、role/session、request/result/decision hash、代码与策略版本可追溯 | WAITING：本轮仅CPU/静态验收，没有真实角色链证据 |
| 科学成功 | 在预定相同预算、空间、种子和设备平衡条件下，AI优于随机对照；效应量、不确定性、独立重复campaign等证据足以支撑限定范围的结论 | WAITING：正式搜索未开始；六次搜索或单条自适应轨迹本身不足以证明 |
| 诚实成功 | 所有失败、timeout、无改善和负结果均完整报告，保留真实身份/哈希/预算；没有优势也如实给出结果、证据与局限 | 本版要求已冻结；后续报告仍须逐项验收 |

只有执行成功不等于科学成功。不能以模型宣称“更新了策略”、预写下一轮参数、mock日志或人工作出下一决定代替真实闭环。至少一个合格事件应有：已校验真实Result → 科研角色可见历史 → 有记录的选择变化 → 下一实际动作。可信决策级对照/重放可帮助判断结果是否起作用，但属于审计模拟，不冒称实验；只写rationale、选择未变或不可解释的随机变化不能自动判定闭环成功。

## 已冻结的基线方法与已报告结果

固定方法见被审查commit的 runner/g3-method.json：只取G3 seeds42/43/44的三次成功最终validation accuracy；算术平均，样本标准差ddof=1，2sigma为探索性噪声提示。任一seed缺失/失败则完整三seed均值与sigma为null，保留个别结果；G1/G2 pilot不混入。实现见runner/campaign_summary.py:records/summary，CPU测试验证了合成输入下的方法逻辑。

2sigma仅作探索提示，不是p值、置信区间、显著性阈值或“AI胜出”判据；n=3估计不稳定。没有达到/超过2sigma都不能单独证明无效/有效。当前不发布未经验证的test成绩。

## 公平比较与统计边界

正式排程见search_schedule.md。Random/AI各六次搜索、每次epochs=3；相同空间和训练种子，按设备交叉平衡。确认使用新seed1001/1002/1003，预算另行授权，不占用/重置旧三槽或两槽。失败和重试消耗预定预算，不能“跑到六次成功”；GPU时间、墙钟、排队以及AI模型推理/编排成本分列披露。

随机候选清单先冻结；AI只能读取共同基线与自身先前搜索结果，不能提前读取随机对照成绩，也不能由操作者转述隐藏对照成绩。必须保留实际prompt/可见信息摘要以审查隔离。

六个相关trial不是六个独立campaign；最佳validation分数存在选优偏差。足够的科学证据应按事前设计进行独立campaign层重复、配对比较、效应与不确定性分析，并明确主要比较及多重比较/停止规则；本版不凭空指定能保证“显著”的重复数或误差阈值。一次冻结的最终测试只能评价选中模型，不能补足策略层统计证据。

所有后续结果报告必须分别给出流程/科学/诚实三项结论，允许“流程成功、未证明科学优势、诚实完整报告”。
